# Rafael Slivca — public website

Static developer website served by GitHub Pages at https://rslivca.github.io/.

This repository contains public website assets only. Game source code is maintained separately.

- `index.html`: developer homepage and app directory
- `coil-me-maybe/index.html`: Coil Me Maybe game page at https://rslivca.github.io/coil-me-maybe/
- `style.css`: shared responsive styling
- `assets/app-icon.png`: game icon
- `app-ads.txt`: shared authorized advertising seller declaration, kept at the domain root
- `.nojekyll`: serve files without Jekyll processing

Add future apps in their own folders and link them from the homepage.
The Coil Me Maybe privacy policy is not published yet. Finalize the public support contact before adding the policy and configuring its URL in AdMob or App Store Connect.

GitHub Pages publishes the root of the `main` branch. No API credentials belong in this repository.
