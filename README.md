# Coil Me Maybe public website

Static website served by GitHub Pages at https://rslivca.github.io/.

This repository contains public website assets only. The game's source code is maintained separately.

- `index.html`: prerelease game information
- `style.css`: responsive page styling
- `assets/app-icon.png`: game icon
- `app-ads.txt`: authorized advertising seller declaration
- `.nojekyll`: serve these files without Jekyll processing

The app privacy policy is not published yet. Finalize the operator identity and public support contact before adding the policy and configuring its URL in AdMob or App Store Connect.

GitHub Pages publishes the root of the `main` branch. No API credentials belong in this repository.
